# Go Fish
___
By Lucian Miller
A game of Go Fish.
___
## Description

Play against a computer in a game of go fish. Collect the most books to win.
The game ends when you, the computer and the deck you draw from is out of cards.
Good luck!

## Setup/Installation Requirements
___

In the terminal application of your choice, follow these steps:

1. Type `git clone https://github.com/lucianmiller/gofish.git`
2. Navigate to the `GoFish` folder in the project directory
3. Type `dotnet restore` to install necessary files
4. Type `dotnet watch run` to start game in your default web browser.
5. Read the rules on the front page and press the "Start Game" button to play
6. To shut off game, either exit out of terminal or press the Shift+C keys in the command line
